손실 경고

악몽처럼 꽉 차서 다음 충전이 버려질 횟수를 미리 빨갛게 알려 줘요.

사용법

  1. 1
    Npcap 설치설치 파일 실행 → 권한 요청에서 '예' → 기본 옵션 그대로 Install
  2. 2
    데바로그 설치"Windows의 PC 보호" 창이 뜨면 [추가 정보] → [실행]
  3. 3
    캐릭터 추가관리표의 [+ 캐릭터 추가]에서 서버와 이름 입력
  4. 4
    게임 접속데바로그를 켜 둔 채 게임에 들어가면 자동 기록 시작
