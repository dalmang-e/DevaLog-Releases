# 데바로그 (DevaLog)

**아이온2 숙제 관리 프로그램.** 켜 두면 여러 캐릭터의 숙제와 재화가 관리표에 자동으로 기록돼요. 무료 Windows 앱이에요.

- 홈페이지: https://dalmang-e.github.io/
- 최신 설치 파일: https://github.com/dalmang-e/DevaLog-Releases/releases/latest

오드, 악몽, 각성전, 루드라, 슈고, 차원 침공, 사명, 히든 큐브 열쇠, 강화석, 키나 같은 아이온2 캐릭터별 숙제를 한 표에서 확인할 수 있어요.

이 저장소는 데바로그 설치 파일 배포와 자동 업데이트에 쓰여요.

데바로그는 비공식 팬 프로그램입니다. AION2 및 관련 상표는 NCSOFT의 자산입니다.
